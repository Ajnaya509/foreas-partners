# Commencer sur Android ou iPhone

Version 2026-09-13.1 - Guide partenaire.

## Page 1 - Commencer sur Android.

Fiche chauffeur · Android

Gardez votre code. Utilisez le même compte avant et après l’installation.

 1. Ouvrir l’invitation Utilisez le lien de la personne qui vous recommande FOREAS. Gardez le code réellement affiché avec « Copier le code ». La visite de la boutique ne prouve pas son rattachement. 2. Installer et retrouver son compte Ouvrez la boutique proposée pour Android depuis votre invitation. Vérifiez la compatibilité de votre appareil et les fonctions disponibles. N’activez une permission que pour une fonction que vous comprenez. Connectez-vous au compte existant ou créez votre premier compte. Si l’app demande le code, saisissez celui de votre invitation avant l’abonnement. 3. Vérifier avant de payer Lisez les formules, le prix, l’essai éventuel et le renouvellement sur la page d’offre. Vérifiez le code proposé. Un code reçu ne garantit pas une remise et ne remplace pas une attribution déjà confirmée. Extrait de l’invitation web. Démonstration locale : ce code ne doit pas être utilisé. 4. Faire un premier essai à l’arrêt Ouvrez l’app avec le même compte. Si nécessaire, utilisez « Débloquer mon accès » sur l’écran d’abonnement. Essayez une fonction réellement disponible et vérifiez que ses informations vous sont utiles. Aucun gain n’est garanti. Pour arrêter le renouvellement : utilisez « Gérer ou arrêter mon abonnement » sur l’écran d’abonnement. Choisissez « Arrêter le renouvellement », puis confirmez sur la page sécurisée. Relisez ensuite l’état : ouvrir ou fermer une page ne prouve pas l’arrêt. Désinstaller l’app ne résilie pas l’abonnement. Cette recommandation peut rémunérer son auteur. La commission n’est pas une remise sur votre prix. Un blocage ou un abonnement introuvable : contact@foreas.xyz . Ne créez pas un second compte pour essayer de le récupérer.
